## 与手册对齐的两处执行口径（不改正文，只定拍法）

1. **天数对不上**：`docs/03` 表头写"3 天（2 天过程 + 1 天集中口播）"，但"拍摄安排"只列了 D-2、D-1 两天。本包按 3 天拆：
   - D1：无犯罪记录证明 + 体检 + 考试
   - D2：租赁公司签约 + 提车验车 + 平台注册 + 夜间空镜
   - D3：集中口播
   > 这样才真的符合"2 天过程 + 1 天口播"，也避免 D1 一天跑 4 个地点导致素材全糊。
2. **报废年限不报死数**：镜 18 的"8 年 / 60 万公里"按手册原提示处理——口播改"当地对营运车辆报废年限有硬性规定"，**字幕不放数字**，避免报错政策。
