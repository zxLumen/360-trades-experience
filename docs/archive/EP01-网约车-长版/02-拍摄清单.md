## 二、场地（6 处 + 1 个主场景）

| 场地 | 拍什么 | 许可 / 风险 | 备用方案 |
|---|---|---|---|
| 家（桌前） | 第 2、6 幕口播 | 背景固定，别换房间 | — |
| 派出所 / 政务大厅 | 无犯罪记录证明办理 | 多数不让拍内部，**先问一句** | 拍门口 + 事后口播"里面不让拍" |
| 医院 / 体检中心 | 体检测视力、色觉 | 只拍自己，不拍其他患者 | 拍候诊区 + 体检单特写 |
| 考场 | 候场、出考场 | 只拍门口与侧背，**不拍他人正脸** | 拍走廊 + 考完表情 |
| 租赁公司 / 停车场 | 看车、签约、合同、提车 | 需销售同意，合同编号打码 | 拍合同封面 + 手写复述条款 |
| 充电站 / 夜间街道 | 空镜 | 公共区域，注意车牌与路人 | 换一个站点补拍 |
| 车内 | 第 1、7 幕 + 全部空镜 | 主场景，光线最好在清晨/傍晚 | 地库补光 |

## 十、翻车预案

| 情况 | 处理 |
|---|---|
| 考场不让拍 | 拍门口 + 事后口播"里面不让拍"，坦白比硬拍好 |
| 租赁公司不让拍合同 | 拍封面 + 手写复述关键条款，编号打码 |
| 某天素材不够 | 用提前拍的空镜垫，配口播覆盖 |
| 审核没过 / 平台拒批 | 这本身就是爆款素材，改标题"我被平台拒了 3 次" |
| 口播状态不好 | 重录，别将就，口播是全片骨架 |
| 环境太吵 | 换场地或回车内补录 |
