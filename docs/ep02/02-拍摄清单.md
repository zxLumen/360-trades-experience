## 二、场地（5 处 + 1 个主场景）

| 场地 | 拍什么 | 许可 / 风险 | 备用方案 |
|---|---|---|---|
| 家（桌前） | 第 2、6 幕口播 | 背景固定，别换房间 | — |
| 派出所 / 政务大厅 | 无犯罪记录证明办理 | 多数不让拍内部，**先问一句** | 拍门口 + 事后口播"里面不让拍" |

| 考场 | 候场、出考场 | 只拍门口与侧背，**不拍他人正脸** | 拍走廊 + 考完表情 |
| 租赁公司 / 停车场 | **问价、报价单、合同样本、演示验车** | 需销售同意；不签约、不付款；公司名/电话打码 | 拍门头 + 口述报价（字幕标"口述报价"） |
| 车内 | 第 1、7 幕 + 空镜 | 主场景，光线最好在清晨/傍晚 | 地库补光 |

## 十、翻车预案

| 情况 | 处理 |
|---|---|
| 考场不让拍 | 拍门口 + 事后口播"里面不让拍"，坦白比硬拍好 |
| 租赁公司不让拍报价单 | 拍门头 + 口述报价，字幕标"口述报价，未签约" |
| 车行不让拍演示验车 | 用停车场空镜 + 手绘示意图，标"示意" |
| 平台注册必须车证、无法继续 | 拍上传页和规则页即可，不硬编、不借车证 |
| 某天素材不够 | 用提前拍的空镜垫，配口播覆盖 |
| 口播状态不好 | 重录，别将就，口播是全片骨架 |
