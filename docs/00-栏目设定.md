# 00 · 栏目设定

> 这一篇是"宪法"。后面所有脚本、剪辑、发布都以这里为准，不轻易改。

---

## 1. 栏目名

| 候选 | 评价 |
|---|---|
| 《我去干了一个月》 | **推荐**。短、口语、可复制："我去开了一个月网约车" |
| 《一个月，我干遍了 360 行》 | 气势足，但名字太长，赛道感弱 |
| 《360 行之…》 | 清晰，但"盘点感"重，容易被当成搬运号 |

**推荐主名**：《我去干了一个月》
**副标/系列名**：360 行体验

---

## 2. 定位

> 一个普通人，用一个月时间真去干一份工作，然后把账本摊开给你看。

- **不是**：行业科普、招聘种草、成功学
- **是**：成本透明 + 门槛实测 + 劝退/推荐

观众看的不是"这行多赚钱"，而是**"如果是我去干，会不会被坑"**。

---

## 3. 基本盘（已定稿）

| 项目 | 设定 |
|---|---|
| 平台 | 抖音 / 视频号 |
| 画幅 | 9:16 竖屏，1080×1920 |
| 单集时长 | 3–5 分钟 |
| 形式 | 真人出镜 Vlog 纪实 |
| 连载 | 一个行业 3–5 期 |
| 数据 | 本人实测 + 多从业者交叉验证 |
| 更新 | 网约车 5 期连发（2–3 天一期），之后每行 1–2 期 |

---

## 4. 人设

- 普通人视角，**不装专家**
- 有具体处境（如失业、转行、想搞副业），让观众有代入
- 会算账，但不算"精明"，算"实在"
- 允许露怯、允许失败，**失败素材往往比成功素材好看**

**口播语气**：像跟朋友讲，不像念稿。多用短句、具体数字、具体场景。

---

## 5. 核心公式

```
悬念钩子(0-8s)
  → 为什么选这行(8-25s)
  → 准备 / 入职纪实(主体)
  → 数据账单上屏(高潮)
  → 谁适合 / 谁劝退(收尾)
  → 下期预告(埋追更)
```

**每期必须有一个"可截图的数字"**——观众截图转发的那一下，就是传播。

---

## 6. 三大系列资产（每期复用，形成视觉签名）

### ① 片头 3 秒

统一音效 + 一句话 Slogan：

> "第 N 行，我干了一个月。"

### ② 统一账单板

同一个模板、同一套配色、同一个 BGM。观众刷到就知道是你。

详见 `templates/账单板模板.md`。

### ③ 固定收尾动作

一张"本月净到手 XXXX 元"大字卡 → 接"下个月，我去干 XX"。

---

## 7. 数据可信度原则

这是整个系列的生命线。

- 流水截图 / 平台后台录屏 / 合同 / 加油充电小票 / 罚单 —— **全部留存并露出**
- 账单里单列一行 **"为了拍视频多花的钱"**，公开透明反而加信任
- 数字分三个口径，永远不混用（见 `07-账单模板与数据口径.md`）：
  - **流水**：平台显示的总收入
  - **到手**：平台实际打给你/可提现的钱
  - **净利**：扣完所有成本后真正剩的钱
- 拿不出凭证的，标"预估"

> 评论区最狠的一句话是"你根本没干过"。所有设计都是为了避免这句话。

---

## 8. 视觉与听觉

| 项 | 设定 |
|---|---|
| 字幕 | 底部安全区，白色 + 黑描边，字号大 |
| 金额 | 黄/红大字单独上屏，**永远不只靠口播** |
| 主色 | 待定（建议账单板用深底 + 荧光黄数字） |
| BGM | 前段 lo-fi 低音量；账单段鼓点 + 数字音效；结尾上扬 |
| 转场 | 硬切 + 快速推近，不用花哨转场 |
| 字幕字体 | 待定（建议免费商用字体，如思源黑体 Heavy） |

---

## 9. 一句话自检

每期发布前问自己：

> **如果观众只记住一个数字，会是哪个？**

如果答不上来，说明这期没做出来。
