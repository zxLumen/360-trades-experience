## 二、三位司机

| 代号 | 类型 | 来源 | 作用 |
|---|---|---|---|
| A | 全职 + 租车 | **EP03 同一位**，已授权 | 主线，观众已经认识 |
| B | 兼职 + 自有车 | 新招募 | 无租金、有折旧的对照 |
| C | 5 年以上老司机 | 新招募 | 收入上限对照 |

**硬条件**：A 必须愿意提供 30 天后台录屏；B/C 至少提供 30 天记账表 + 月底后台截图。缺一个就降级为两栏。

---

## 三、数据采集（EP04 的命）

1. **30 天窗口**：EP03 发布当天开始，每人一张 `docs/07` §五 记账表，每天填，周末拍照回传。
2. **月底同一天对账**（3 场，每场 2h）：
   - 后台 30 天总流水录屏，一镜到底
   - 可提现 / 银行卡到账截图
   - 租金、电费/油费、保养、保险、罚单票据
3. **三个口径不混**：流水 / 到手 / 净利；时薪 = 净利 ÷ 总工时（不是在线时长）。
4. **押金单列**：资产不是成本，退不了才算损失。
5. **拿不到凭证的项标"预估"**，并在账单板上标出来。

## 六、合规红线

- 乘客：不拍正脸、不录声音；车内涉及乘客的素材一律不用。
- 订单号 / 手机号 / 车牌：打码。
- 司机：授权书写清用途、平台、打码方式，可随时要求下架。
- 平台规则：不诱导私下交易，不教规避监管。
- 数据：所有金额对得上后台录屏，不"帮司机美化"。
- 商业合作：如涉及租赁公司/平台，片中必须标"广告"。
