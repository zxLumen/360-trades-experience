# 04 · 剪辑与发布规范

---

## 一、画面与字幕

| 项 | 标准 |
|---|---|
| 画幅 | 9:16，1080×1920 |
| 帧率 | 30fps（口播）/ 60fps（车内运动镜头可选） |
| 字幕位置 | 底部安全区，距底边 ≥ 15%（避开平台 UI） |
| 字幕样式 | 白色 + 黑描边，字号大，一行不超过 12 字 |
| 金额 | **黄 / 红大字单独上屏**，永远不只靠口播 |
| 字体 | 免费商用字体（如思源黑体 Heavy），不要用系统默认宋体 |
| 人名/车牌/订单号 | 一律打码 |

### 字幕断句原则

- 一句话一行，不要跨行
- 数字单独成行，视觉上"砸"出来
- 语气词（"啊""就是"）不进字幕，只留信息

---

## 二、节奏

| 段落 | 切镜频率 |
|---|---|
| 钩子（0–8s） | 每 2–4 秒一切，越快越好 |
| 人物建立 | 可放宽到 8–10 秒 |
| 过程纪实 | 每 3–5 秒一切，用快剪制造密度 |
| 账单段 | 靠动画节奏，不靠切镜 |
| 收尾 | 放慢，留白 |

**硬规则**：任何一镜停留超过 10 秒且没有新信息，观众就走了。

---

## 三、声音

| 元素 | 处理 |
|---|---|
| 人声 | 响度拉满，做降噪 + 压缩 |
| 环境音 | 降到 −25dB 左右，保留一点空间感 |
| BGM | 人声段 −18dB 左右，账单段可提到 −12dB |
| 音效 | 数字弹出"咔"、金额砸出"低频轰"、转场"whoosh" |

**BGM 情绪曲线**

```
前段：lo-fi / 轻电子，低音量，铺垫
中段：节奏加快，鼓点进入
账单：鼓点 + 数字音效，最满
收尾：单音色上扬，留 2 秒空白
```

> 全部使用平台音乐库内的可商用曲目，避免版权风险。

---

## 四、封面

**规格**：竖版 3:4 或 9:16，主体在中间 60% 区域（各平台裁切不同）

**结构**
```
[超大字数字]      ← 占画面 40%，必须一眼看清
[一句短标题]      ← 8 字以内
[人脸/场景]       ← 表情要有情绪（惊讶/疲惫/苦笑）
```

**示例**
> 还没上路
> 先花【6800】

**禁止**
- 封面放 5 行以上文字
- 用与内容不符的夸张标题（会被判标题党，掉权重）

---

## 五、标题公式

选一个，别堆砌：

| 公式 | 示例 |
|---|---|
| 数字反差 | 流水一万二，到手三千八 |
| 门槛 + 代价 | 花 6800 块，我才拿到开网约车的资格 |
| 身份 + 处境 | 35 岁失业，我决定去开网约车 |
| 提问式 | 想开网约车？先看看这 6800 块怎么没的 |
| 劝告式 | 想入行网约车，先看这 7 条 |

**标题里必须有**：具体数字 / 具体身份 / 具体冲突（至少两个）。

## 六、发布流程

### 发布前 checklist

- [ ] 3 秒完播率自测：把开头单独看 3 遍，会不会想划走
- [ ] 所有金额是否与凭证一致
- [ ] 是否有人脸、车牌、订单号未打码
- [ ] 字幕是否有错别字（尤其数字和小数点）
- [ ] 封面在手机小屏上是否看得清
- [ ] 标题是否包含数字
- [ ] 话题标签 5–8 个，含 1 个大流量 + 2 个垂类 + 2 个系列标签
- [ ] 置顶评论是否已准备（补充干货 / 引导互动）
- [ ] 是否已排好下期预告

### 标签组合

```
大流量：#副业 #搞钱 #职业体验
垂类：  #网约车 #跑网约车 #滴滴司机
系列：  #我去干了一个月 #360行体验
```

### 评论区运营

- 发布后 30 分钟内回复前 20 条评论（算法加权）
- 置顶一条"干货补充"，把视频里没讲完的细节写进去
- 置顶第二条引导追更："下期开始接单，想看真实流水吗"
- 遇到质疑"你根本没干过"，**直接甩凭证**，不要吵
