# 03 · EP01 · 准备期 · 拍摄脚本

**《还没上路，我先花了【6800】块》**

| 项目 | 设定 |
|---|---|
| 时长 | 约 4 分 10 秒 |
| 画幅 | 9:16 竖屏 1080×1920 |
| 形式 | 口播 + 过程纪实 |
| 拍摄天数 | 3 天（2 天过程 + 1 天集中口播） |

> 方括号 `【】` 里的数字是**占位符**，拍摄当天必须换成真实金额。
> 拿不出凭证的一律标"预估"，不许编。

---

## 一、开拍前：物资清单

### 设备（缺一不可）

- [ ] 手机主机 + 备用机
- [ ] **领夹麦 ×1** ← 车里、户外必须用，新手最容易翻车的地方
- [ ] 车内手机支架 / 吸盘支架
- [ ] 补光灯（室内口播）
- [ ] 充电宝 + 数据线
- [ ] （可选）三脚架、稳定器

### 道具

- [ ] 证件实物：身份证、驾驶证、人证、行驶证、车证、保险单
- [ ] 租车合同（拍时打码关键信息）
- [ ] 所有缴费凭证 / 收据 / 转账记录
- [ ] A4 白纸 + 马克笔（手写算账用）
- [ ] 固定服装（口播连戏用，全程同一件）

### 必拍证据素材

- [ ] 无犯罪记录证明办理过程

- [ ] 方向盘特写、后视镜、计价器

## 二、拍摄安排

| 时间 | 拍什么 | 备注 |
|---|---|---|
| **D-2 上午** | 无犯罪记录证明、体检 | 带齐证件 |
| **D-2 下午** | 考试、租赁公司、提车验车 | 考场侧拍，不拍他人正脸 |
| **D-2 傍晚** | 平台注册、空镜补拍 | 空镜多拍 5 分钟素材 |
| **D-1 全天** | **集中口播** | 同一件衣服、同一机位、同一背景，一次说完 |

> **核心原则：口播集中拍，过程随手拍。**
> 口播必须同一件衣服（连戏），过程素材可以换装。
> 口播顺序按脚本念即可，不用按时间顺序，剪的时候再排。

## 五、拍不到怎么办（备用方案）

| 情况 | 处理 |
|---|---|
| 考场不让拍 | 拍门口 + 事后补口播："里面不让拍，我口述一下"——**坦白比硬拍好** |
| 租赁公司不让拍合同 | 拍封面 + 手写复述关键条款，合同编号打码 |
| 某天素材不够 | 用提前拍的空镜（方向盘、充电站、凌晨街道）垫，配口播覆盖 |
| 审核没过 / 平台拒批 | **这本身就是爆款素材**，改标题为"我被平台拒了 3 次" |
| 口播状态不好 | 重录，别将就。口播是全片的骨架 |

## 六、这期最容易犯的 3 个错

1. **开头 8 秒没数字** → 一定被划走。第一句必须出现金额。
2. **只口播不上屏** → 静音观看的人直接流失，所有金额都要上屏。
3. **收音不干净** → 车内、马路边的噪音毁掉整条片子。领夹麦是刚需，不是可选项。
