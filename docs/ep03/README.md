## 一、为什么改成跟拍

| 项 | 原方案（真投 1 万跑满月） | 现方案（跟拍） |
|---|---|---|
| 现金支出 | 约 10,000 元（押金 + 首月租金） | **0–500 元**（车马费 + 请司机吃饭） |
| 周期 | 30 天 | **1 天拍摄 + 2 天后期** |
| 数据来源 | 自己后台 | 司机后台（授权录屏） |
| 真实性风险 | 高（一个月内可能退车） | 中（必须写明「我跟了一天」，不冒充） |
| 可回滚 | 押金可能拿不回 | 拍废只损失 1 天 |

**代价**：拿不到「我自己干了一个月」的第一人称叙事，只能拿到「他跟了一天」的观察视角。所以**标题和口播必须明确第三人称**，这是本包的硬边界。

## 五、边界

- **不冒充从业者**：标题、封面、口播三处都必须出现「跟拍 / 我跟了一天」。
- 不拍乘客正脸、不录乘客声音、不拍车牌、不拍平台名与司机真名（见 `04-素材清单与合规.md`）。
- 司机说「这段别拍」立即停机，不解释、不劝。
- 不承诺收益、不出现「月入过万」类表述；所有数字带截图或标「口述」。
- 本包不招募、不拍摄、不发布——招募是下一个动作。
