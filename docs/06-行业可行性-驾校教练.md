# 06 · 行业可行性：驾校教练

> 这是一个"看起来很适合拍、实际很难拍"的行业。
> 直接照搬"我干了一个月教练"会翻车，必须改拍法。

---

## 一、为什么不能直接拍

| 障碍 | 说明 |
|---|---|
| **资质门槛** | 通常要求 C1 及以上驾照 + 3～5 年驾龄 + 无重大事故 + 教练员证（各地不同） |
| **雇佣关系** | 驾校基本不接受"只干一个月"的临时工，涉及带学员、安全责任、教学资质 |
| **法律风险** | 无教练员证进行教学活动属于违规，且一旦学员出事责任极大 |
| **拍摄限制** | 教练车内有学员，涉及肖像权；部分驾校禁止拍摄 |

**结论**：**不要用"我当了一个月驾校教练"做标题**。这是系列里唯一一个必须换拍法的行业。

---

## 二、三个可执行方案

| 方案 | 做法 | 优点 | 缺点 | 推荐度 |
|---|---|---|---|---|
| **A. 改成"汽车陪练"** | 陪练门槛低：有驾照 + 无事故 + 自有车即可接单，可真的干满一个月 | 完全符合系列模式，且和网约车强关联 | 不是"驾校教练"，标题别写死 | ⭐⭐⭐⭐⭐ |
| **B. 考证 + 跟拍** | 真去考教练员证（过程本身就是内容），再跟拍一位在职教练一整天 | 标题可写"我考了教练证"，独家过程感 | 只能"跟拍"，不能算"我干了一月" | ⭐⭐⭐⭐ |
| **C. 采访 + 跟车** | 找 2–3 位在职教练，跟车一整天 + 拆解收入 | 成本最低 | 最容易被质疑"你根本没干" | ⭐⭐ |

---

## 三、推荐方案：拆成两集

### EP-A《我花了 X 个月，考出了驾校教练证》

**定位**：考证纪实 + 门槛科普

**内容结构**
```
钩子：为了当教练，我先花了 XXXX 块、X 个月
→ 报名条件（驾龄、无事故、学历要求）
→ 理论与实操培训
→ 考试（科目：理论 / 教学法 / 实操）
→ 拿证
→ 账单：报名费 + 培训费 + 体检 + 证件
→ 钩子：有证了，但驾校不要我
```

**核心冲突**：**有证 ≠ 有岗**。这是最真实的行业现实，也是最好的内容。

### EP-B《跟着一位教练，上了 8 小时车》

**定位**：第三人称跟拍 + 收入拆解

**内容结构**
```
钩子：一个驾校教练，一天到底赚多少
→ 早 6:30 到场地
→ 带 4 个学员，重复同一句话 200 遍
→ 中午吃饭 20 分钟
→ 下午继续，晒到脱皮
→ 晚上算账：带一人提成 X 元
→ 教练自述：这行的坑（招生压力、学员投诉、驾校抽成）
→ 结论：适合什么人
```

## 四、收入结构（拍摄时需要问清的问题）

访谈时逐条问，别怕细：

1. 底薪还是纯提成？
2. 带一个学员提多少？科目二、科目三分开算吗？
3. 学员考试通过率跟收入挂钩吗？
4. 油费、车辆损耗谁承担？
5. 招生任务有没有？完不成扣钱吗？
6. 一天最多带几个？一个月最多带几个？
7. 淡旺季差别多大？（寒暑假 vs 平时）
8. 五险一金有没有？签的是劳动合同还是合作合同？
9. 干这行最难受的是什么？
10. 如果重来，还会干吗？

## 五、更优的替代：汽车陪练

如果目标是"真的干一个月"，**汽车陪练**是更好的选择：

| 维度 | 驾校教练 | 汽车陪练 |
|---|---|---|
| 资质 | 教练员证 + 挂靠 | 驾照 + 无事故 + 自有车 |
| 雇佣 | 需驾校录用 | 平台注册即可 |
| 实测可行性 | 低 | **高** |
| 与网约车的关联 | 弱 | **强（同一个生态）** |
| 单价 | 按学员提成 | 按小时收费，单价更高 |

**建议排期**：先做"汽车陪练"（EP04 位置），再做"驾校教练考证 + 跟拍"（EP09 位置）。两者还能互相导流。

## 六、标题红线

| ❌ 不能写 | ✅ 可以写 |
|---|---|
| 我当了一个月驾校教练 | 我花三个月考出了驾校教练证 |
| 驾校教练真实收入（我亲测） | 我跟了一位驾校教练一整天 |
| 无证也能带学员 | 想当教练？先看这三个条件 |
| 教你如何快速拿教练证 | 教练证考试全流程记录 |

---

## 七、拍摄注意

- 教练车内拍摄必须获得驾校和学员双方同意
- 学员一律打码，最好只拍手部、脚部、后视镜
- 不在行驶中干扰教练操作
- 涉及"通过率""包过"等承诺，一律不拍不说
