# 07 · 账单模板与数据口径

> 账单板是这个系列的**视觉签名**，也是观众截图转发的东西。
> 所有行业共用一套结构，只换条目。

---

## 一、三个口径（必须严格区分）

| 口径 | 定义 | 计算方式 |
|---|---|---|
| **流水** | 平台显示的总收入，未扣任何费用 | 平台后台"总流水" |
| **到手** | 平台实际打给你 / 可提现的金额 | 后台"可提现"或银行卡到账 |
| **净利** | 扣完所有真实成本后剩下 | 流水 − 抽成 − 租金 − 油电 − 保险 − 保养 − 吃饭 − 违章 − 装备 |

**表述规范**

- ✅「我这个月流水一万二，到手八千，净利三千八」
- ❌「我这个月赚了一万二」
- ❌「到手三千八」（不说是流水还是净利）

---

## 二、统一字段

### 收入侧

| 字段 | 说明 |
|---|---|
| 平台流水 | 后台总流水 |
| 现金收入 | 线下/私单（如有，需说明合规性） |
| 平台奖励 | 冲单奖、时段奖、新人奖 |
| **收入合计** | |

### 成本侧

| 字段 | 说明 | 是否固定 |
|---|---|---|
| 平台抽成 | 流水 × 抽成率 | 变动 |
| 车辆租金 | 租车模式才有 | 固定 |
| 车辆折旧 | 自有车才有（按里程/年限摊） | 固定 |
| 油费 / 电费 | 按实际票据 | 变动 |
| 保险 | 按月摊销 | 固定 |
| 保养维修 | 按月摊销 | 变动 |
| 停车费 / 过路费 | 按实际 | 变动 |
| 吃饭 / 饮水 | 按实际 | 变动 |
| 违章罚款 | 按实际 | 变动 |
| 装备（支架、充电宝、坐垫等） | 一次性 | 一次性 |
| **成本合计** | | |

### 时间侧

| 字段 | 说明 |
|---|---|
| 总工时 | 从出车到收车的全部时间 |
| 在线时长 | 平台显示在线时间 |
| 有效接单时长 | 真正在载客/配送的时间 |
| **折算时薪** | 净利 ÷ 总工时 |

> **时薪是杀手锏。** 月入过万听起来很好，折成时薪可能不如送外卖。

## 四、通用行业模板

换行业时，只改"成本侧"的条目：

| 行业 | 特有成本项 |
|---|---|
| 外卖 / 闪送 | 电动车折旧、换电费、餐损、超时罚款 |
| 代驾 | 折叠车、平台抽成、夜间返程 |
| 摆摊 | 摊位费、食材损耗、天气损失、设备 |
| 家政保洁 | 交通、耗材、平台会员费 |
| 宠物寄养 | 场地、疫苗、意外医疗 |
| 直播助播 | 通勤、服装、设备 |
| 剧本杀 DM | 通勤、嗓子药、剧本费 |

## 七、常见错误

| 错误 | 后果 |
|---|---|
| 把押金算进成本 | 数字虚高，被评论区抓 |
| 用流水当收入 | 被认为造假 |
| 不扣自己的吃饭钱 | 净利虚高 |
| 只算在线时长不算真实工时 | 时薪虚高 |
| 月底凭记忆补账 | 数字对不上，可信度崩塌 |
| 把平台奖励算成额外收入却不提冲单成本 | 片面 |
