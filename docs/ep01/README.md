## 一、为什么是这行

| 维度 | 这行的答案 | 对拍摄的意义 |
|---|---|---|
| 30 分钟能拍完 | 一个卫生间、一个机位、一个人，净拍摄 ≤ 30 分钟 | 不用请假、不用跑外景 |
| 0 元启动 | 洁厕剂/抹布/刷子家里有；没有就用白醋+小苏打、旧毛巾、旧银行卡 | 0 采购、0 待补 |
| 0 许可 | 不进经营场所、不拍他人、不涉及证件 | 没有“场地不让拍”的风险 |
| 数据可验证 | 平台报价截图 + 招聘时薪截图 + 手机计时，三证同框 | 评论区质疑时直接甩图 |
| 情绪点明确 | 180  vs 30 的落差、蹲着擦边角、手泡皱 | 有反差、有体力感、有讨论点 |

> 这是系列的**30 分钟快拍试拍集**：先用最低成本验证“拍摄 → 剪辑 → 发布”链路，再上需要 3 天/21 小时的网约车长版。原 `docs/EP01/` 网约车长版已归档到 `docs/archive/EP01-网约车-长版/`，顺延为 EP02 参考。

## 六、边界

- **本包不开拍、不发布。** 开拍是下一个动作，发布是再下一个动作。
- 本集是 30 分钟试拍集，只验证“单次工时 + 平台报价”，**不声称月收入、不假装干了一个月**；月数据留给后续长版。
- 不拍家人正脸、不拍窗外门牌、不拍可识别的小区名。
- 洁厕剂（酸性）**不能**和 84 消毒液混用；开窗通风，戴手套。
- 数据口径：本期说的是“阿姨到手工钱”，不是“平台客单价”，也不是“净利”；三个词不混用。
