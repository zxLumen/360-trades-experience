# 02 · 网约车 · 分集大纲（5 期连载）

> 开篇行业。目标：用 5 期把"网约车到底能不能干"这件事讲透，同时跑通系列的拍摄和剪辑 SOP。

---

## 总览

| 期 | 标题方向 | 核心内容 | 结尾钩子 |
|---|---|---|---|
| EP01 | 《还没上路，我先花了 XXXX》 | 办人证 → 车证 → 租车 → 平台注册 | "明天正式上路" |
| EP02 | 《新手第一周：流水 4800，到手 1900》 | 真实接单、早晚高峰、机场、充电、第一次差评 | "这只是开始，满月才算账" |
| EP03 | 《满月账单》**（招牌集）** | 全月流水逐项拆解 | "流水一万二，到手三千八——为什么？" |
| EP04 | 《三个人，三种活法》 | 全职租车 / 兼职自有车 / 老司机 | "所以这行到底能不能干？" |
| EP05 | 《想入行？先看这 7 条》 | checklist + 避坑 + 劝退人群 | 引出下一行 |

> 数据一般时可砍到 4 期：EP04 与 EP05 合并。**EP03 不能砍，那是整个系列的立身之本。**

## EP01 · 准备期

**目标**：让观众看到"还没赚钱就先花钱"，建立成本意识。

**必拍素材**
- 无犯罪记录证明办理
- 体检（视力、色觉、听力）
- 刷题 App（题库数量特写）
- 考场门口 / 候场人群（侧背或虚化）
- 租赁公司签约桌、合同条款特写
- 提车绕车验车视频（每道划痕）
- 平台注册全流程、审核中、接单页亮起

**账单重点**：报名费、体检费、证件照、无犯罪证明、租车押金、首月租金、平台保证金

**钩子**：还没接一单，已花 XXXX 元。

**完整脚本**：见 `03-EP01-准备期-拍摄脚本.md`

---

## EP02 · 新手第一周

**目标**：用"看着还行的流水"制造假象，为 EP03 的反差做铺垫。

**必拍素材**
- 凌晨出车、第一单接单瞬间
- 早高峰 / 晚高峰对比
- 机场排队（等待时长、排队序号）
- 充电站排队 / 换电 / 加油
- 第一次被差评（打码）、申诉过程
- 平台奖励规则页面
- 每日流水记录本

**数据设计（关键）**
- 只讲 **流水** 和 **到手**，先不扣全部成本
- 让观众产生"好像也能赚"的错觉
- 结尾抛一句："这个数看着还行，但还没算完。"

**账单重点**：一周流水、平台抽成、租金摊销、电/油费

**钩子**：流水 4800，到手 1900。

---

## EP03 · 满月账单（招牌集）

**目标**：全系列的情绪最高点。这一集决定账号能不能起来。

**必拍素材**
- 月度后台流水录屏（最关键）
- 每一天的记账本翻页
- 充电 / 加油小票堆叠
- 罚单（如有）
- 保养 / 维修单
- 吃饭的账单
- 最后一天收车、熄火

**账单结构**

```
【总收入】平台流水 / 现金 / 平台奖励
【扣 除】平台抽成 / 租金 / 电油费 / 保险 / 保养维修
【杂 项】吃饭 / 停车 / 违章罚款 / 装备
【净 利】= 总收入 − 全部扣除
【时 长】总工时 / 有效工时 → 折算时薪
【一句话结论】谁适合干 / 谁别碰
```

**必算的三个数**
1. 净到手多少
2. **折合时薪多少**（这个最扎心）
3. 如果按自有车算，能多拿多少

**钩子**：流水一万二，到手三千八。

---

## EP04 · 三个人，三种活法

**目标**：把"网约车不赚钱"这个结论细化——不是行业不行，是模式不同。

**三种模型**

| 模型 | 成本结构 | 月净利范围 | 适合谁 |
|---|---|---|---|
| 全职 + 租车 | 租金高、无资产 | 最低 | 没钱、想先试水 |
| 兼职 + 自有车 | 无租金、有折旧 | 中等 | 有主业、想补收入 |
| 全职 + 自有车 | 折旧 + 保养 | 最高 | 长期干、能吃苦 |

**必拍素材**
- 访谈 2–3 位不同模式的司机（打码/变声可选）
- 老司机的记账本、车辆里程表
- 停车场、司机休息点

**钩子**：同一辆车，有人月入过万，有人倒贴。

---

## EP05 · 想入行？先看这 7 条

**目标**：给系列一个"有用"的落点，提升收藏和转发。

**内容框架（7 条）**
1. 先确认本地双证要求，别先租车
2. 押金条款逐字看，退车条件写清楚
3. 首月别签长约，先跑 7 天验证
4. 算清"时薪"，不要只看流水
5. 违章罚款谁承担，写进合同
6. 保险必须齐（交强 + 商业 + 座位险）
7. 身体能不能扛：久坐、憋尿、饭点不定

**劝退人群**：指望轻松月入过万 / 不愿长时间在线 / 无法承受押金损失 / 有严重腰椎颈椎问题

**钩子**：下一行，你们投票。

## 系列连续性设计

- **同一辆车、同一件外套**出现在 5 期里，形成"连续剧"感
- EP01 的账单板数字，在 EP03 里回扣（"第 0 天花的那 XXXX，摊到一个月是多少"）
- 每期结尾统一大字卡，只有行业名和金额在变
