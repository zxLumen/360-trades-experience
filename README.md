# 360 行体验 · 我去干了一个月

> 一个短视频系列的完整创作手册：选题、脚本、拍摄、剪辑、发布、复盘。

**一句话定位**：真人出镜，真的去干满一个月，然后把真实成本和真实到手拆给观众看。

---

## 这是什么

这不是一个"盘点 360 行"的口播号，而是一个**用真实投入换取真实数据**的纪实系列。

每一行都遵循同一个公式：

```
悬念钩子(0-8s) → 为什么选这行 → 准备/入职纪实 → 数据账单上屏 → 谁适合/谁劝退 → 下期预告
```

系列真正的护城河不是"体验"，而是**别人抄不走的一个月**——流水截图、合同、罚单、体检单，全部留证。

## 怎么用

**要拍新的一期时，按这个顺序：**

1. 读 `docs/01` 确认选题评分 → 值得做再投入时间
2. 读 `docs/06` 确认这行的**准入可行性**（能不能真的"干一个月"）
3. 复制 `templates/单集脚本模板.md` 写出逐镜脚本
4. 用 `templates/拍摄清单.md` 备物料、列必拍镜头
5. 拍完按 `docs/07` 填真实数字，按 `templates/账单板模板.md` 出图
6. 按 `docs/04` 剪辑发布，按 `docs/05` 做合规检查

## 三条铁律

1. **数字必须真实。** 拿不出凭证的，标"预估"，绝不编。
2. **每一行都要真的干。** 干不了就明说"只能跟拍"，标题不许骗人。
3. **每月固定拍空镜。** 方向盘、充电站、凌晨街道、计价器——素材荒时能救命。
