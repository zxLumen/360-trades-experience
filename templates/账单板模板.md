# 账单板模板

> 系列视觉签名。所有行业共用同一版式，只换条目和颜色。

---

## 设计规范

| 项 | 规范 |
|---|---|
| 画幅 | 9:16 竖版，占满全屏 |
| 背景 | 深色（近黑 #111），或实拍背景 + 80% 黑色蒙版 |
| 主色 | 荧光黄 #FFE066（数字）／ 警示红 #FF4D4F（结论/亏损） |
| 字体 | 思源黑体 Heavy，数字用等宽字体 |
| 对齐 | 左对齐条目，右对齐金额 |
| 分隔线 | 1px 深灰，只用在"合计"之前 |
| 出场 | 逐行弹出，每行 0.3s，配"咔"音效 |
| 结论 | 最后一行放大 1.5 倍 + 轻微震动 |

**禁止**：花哨背景、超过 2 种颜色、在账板上放表情包。

## 版式 B · 反差版（用于钩子和封面）

把两个数并排放大，视觉对撞：

```
┌────────────┬────────────┐
│            │            │
│  流  水    │  净  利    │
│            │            │
│  12,000    │   3,150    │
│            │            │
└────────────┴────────────┘
     差了 3.8 倍
```

**用途**：EP03 的开场 3 秒、封面、图文预告。

## 版式 C · 时薪版（最扎心）

```
本月净利      【 3,150 】
总 工 时      【 300 小时 】

────────────────────

折合时薪      【 10.5 元/时 】

比【当地最低时薪】还【低/高】X 元
```

> 这个版式适合做单张图文，传播力极强。

---

## 动画脚本（账单段专用）

| 时间 | 动作 | 音效 |
|---|---|---|
| 0.0s | 账板淡入 | 低频 "whoosh" |
| 0.3s | 第一行弹出 | "咔" |
| 每 0.3s | 下一行弹出 | "咔" |
| 合计行 | 放大 + 停顿 0.5s | 重音 "咚" |
| 净利行 | 变红 + 震动 | 低频轰 |
| 时薪行 | 单独淡入 | 静音 1 秒 |
| 收尾 | 全部淡出 | 留白 |

## 数据填写检查

发布前确认：

- [ ] 所有金额与凭证一致
- [ ] 押金没有算进成本（或已单独标注）
- [ ] 流水 / 到手 / 净利三个词没有混用
- [ ] 时薪是按**总工时**算的，不是在线时长
- [ ] 没有凭证的项已标"预估"
- [ ] 平台奖励已计入收入
- [ ] 自己的吃饭钱已扣除
