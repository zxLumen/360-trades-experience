# 拍摄清单（通用）

> 每次开拍前打印/复制这一页，逐项打勾。少一样都可能白跑一天。

---

## 一、出发前（前一晚检查）

### 设备

- [ ] 手机主机（电量 100%）
- [ ] 备用机
- [ ] **领夹麦 + 备用电池**（最容易忘）
- [ ] 麦克风接收器（Type-C / Lightning 转接头）
- [ ] 车内支架 / 吸盘
- [ ] 三脚架
- [ ] 补光灯 + 支架
- [ ] 充电宝（满电）
- [ ] 数据线 ×2
- [ ] 存储空间 ≥ 50GB

### 道具

- [ ] 证件（身份证、驾驶证、相关资格证）
- [ ] 合同 / 收据 / 缴费凭证
- [ ] A4 白纸 + 马克笔
- [ ] 固定服装（口播连戏）
- [ ] 湿巾（擦镜头）

### 素材准备

- [ ] 今天的必拍镜头清单（从脚本抄一份）
- [ ] 需要问的问题清单（访谈用）
- [ ] 授权话术（打印或存手机）

---

## 二、现场必拍

### 通用五件套（每期都要）

- [ ] **开场钩子素材**——与核心数字相关的画面
- [ ] **过程素材**——排队、签字、等待、走路
- [ ] **手部特写**——签字、数钱、拿证件、握方向盘
- [ ] **环境空镜**——招牌、门头、街景、天空
- [ ] **收尾镜头**——离开、关门、车远去

### 情绪镜头（最容易被忽略）

- [ ] 皱眉 / 叹气 / 苦笑
- [ ] 看手机的表情
- [ ] 等待时的无聊
- [ ] 完成后的松一口气

> 这些镜头后期能救命。没有情绪镜头，片子就是流水账。

---

## 三、录制规范

| 项 | 要求 |
|---|---|
| 横竖 | **全程竖屏 9:16**，不要中途切横屏 |
| 帧率 | 30fps（口播）/ 60fps（运动） |
| 对焦 | 每次开拍前点一下人脸锁定 |
| 曝光 | 用手动曝光锁定，避免明暗跳变 |
| 收音 | 领夹麦必开，开拍前说"测试一二三"回听 |
| 时长 | 每条至少录 10 秒多余，方便剪辑 |
| 口播 | 一次录 3 遍，选最自然的一遍 |

---

## 四、口播专项

- [ ] 同一件衣服
- [ ] 同一机位、同一背景
- [ ] 眼睛看镜头（不是看屏幕）
- [ ] 语速比平时慢 10%
- [ ] 每句结尾停顿 1 秒，方便剪
- [ ] 说错不要停，重说一遍即可

**口播前热身**：大声念 3 分钟稿子，把嘴皮子活动开。第一遍永远是最僵的。

---

## 五、收工前 10 分钟

- [ ] 回放今天的素材，确认关键镜头没糊、没录上
- [ ] 补拍遗漏镜头
- [ ] 导出/备份到电脑或云盘（**当天备份，别过夜**）
- [ ] 按日期建文件夹归档
- [ ] 记录今天遇到的问题（下次改进）

## 七、常见翻车点

| 问题 | 后果 | 预防 |
|---|---|---|
| 忘带领夹麦 | 全片废掉 | 前一晚放包里 |
| 存储满 | 拍到一半停 | 出发前清 50GB |
| 中途换衣服 | 连戏断裂 | 口播集中一天拍 |
| 只拍"成功"画面 | 没有情绪 | 主动拍失败和等待 |
| 当天不备份 | 素材丢失 | 收工立即备份 |
| 环境太吵 | 无法使用 | 换场地或补录口播 |
| 忘拍空镜 | 后期没素材垫 | 每次多拍 5 分钟 |
